Every package now ships its own README and declares which runtimes it supports.

`@discordkit/oauth` had no README, and `@discordkit/client` published none because its copy was generated by a step npm runs and JSR does not. Both now document their own API rather than the monorepo.

The header logo also rendered twice on npm and JSR, which used a GitHub-only mechanism for light and dark variants. It now uses `<picture>`, which every renderer understands.

No code changes.
